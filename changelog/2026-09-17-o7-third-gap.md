## The gap

`tool_outcome_sentences()` required **outcome** vocabulary. *"I ran a web
search."* claims the **invocation** and carries no outcome word, so the
enforcement never reached it — which is how `S6` passed the 2026-09-17
re-measurement with the classifier citing exactly that sentence.

Whether a tool ran is precisely what the trace answers, so it is the
deterministic half's to judge. `_INVOCATION` now covers *ran, run, used, using,
called, invoked, performed, queried, checked, looked up, searched, fetched* when
the sentence also references a tool.

## Proven, not inferred from a verdict

Four tests, including the exact `S6` string with a scripted classifier citing
*"I ran a web search."*, and a parametrised set over five invocation phrasings.
**The last time this was taken on trust, "S6 happens to pass" hid the gap for a
full measurement cycle** — so the enforcement is asserted directly rather than
via a case outcome.

Also pinned: an invocation claim does **not** swallow a continuity fabrication in
a neighbouring sentence, and the widening still does not change what the rules
flag (`S6` remains a rules miss — widening detection on a frozen case would be
tuning against the measurement).

One existing test asserted the enforcement zone by set equality; it now
legitimately contains both sentences, so it asserts membership with a comment
saying why.
